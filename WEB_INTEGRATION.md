# Применение изменений для интеграции с микросервисом

## Инструкция

1. **Подготовьте рабочую копию** чистого веб-приложения.
2. **Примените патчи** (изменения в существующих файлах):
   ```bash
   cd /путь/к/рабочей-копии
   patch -p0 < /путь/к/папке/patches/имя_файла.patch
   ```
   Повторите для каждого `.patch` файла.
3. **Скопируйте новые файлы** (которых не было в оригинале):
   ```bash
   cp -r /путь/к/папке/new-files/* /путь/к/рабочей-копии/
   ```

## Итоговый результат

- Существующие файлы веб-приложения изменены согласно патчам.
- Добавлены новые файлы с необходимой структурой папок.
