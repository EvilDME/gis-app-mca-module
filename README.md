# GIS MCA Module

Проект для мультикритериального анализа геоданных.

## Как запустить проект
1. **Создайте виртуальное окружение** (используем Python 3.12):
   ```bash
   py -3.12 -m venv venv
   ```
2. **Активируйте окружение**:
   ```bash
   .\venv\Scripts\Activate.ps1
   ```
3. **Установите зависимости**:
   ```bash
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```
4. **Отредактируйте .env**
   Необходимо задать:
   POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_DB – для PostGIS.
   MINIO_ROOT_USER, MINIO_ROOT_PASSWORD – для MinIO.
   MINIO_PUBLIC_HOST – хост, по которому браузер будет обращаться к MinIO (например, localhost).
   JWT_SECRET – секретный ключ для верификации JWT (Верификация пользователей веб-приложения).
5. **Запуск Контейнеров**:
   Убедитесь, что Docker Desktop запущен, и выполните команду:
   ```bash
   docker-compose up -d --build
   ```
## Сервисы (контейнеры)
   PostGIS – порт 5433. БД доступна по localhost:5433.

   MinIO – порт 9000 (S3 API), 9001 (Web‑консоль). Бакет rasters создаётся автоматически с публичным доступом и CORS.

   MCA‑сервис (FastAPI) – порт 8000.

## Эндпоинты
   Список всех эндпоинтов можно посмотреть в Swagger‑документации: http://localhost:8000/docs.

## PostGIS
   
   !!! Для подключения pgAdmin к БД развернутой в Docker может понадобиться отключить службу postgre в services.msc. Локальный PostGRE работать, следовательно, не будет. Так как БД развернута на другом порте (5433) такой необходимости быть не должно и она может работать одновременно с БД, работающей на основной машине (5432).
   
   Чтобы подключиться к БД через pgAdmin: ПКМ по Servers - Register - Server - Connection - Указать данные из .env

   В проекте есть файлы для автоматической инициализации БД, но возможно они устарели и не соотвествуют использующимся в проекте моделям.
