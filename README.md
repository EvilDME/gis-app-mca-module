# GIS Analytics Project (MCA Module)

Проект для мультикритериального анализа геоданных (растры высот, дорожные сети, реки).

## Как запустить проект (Windows)

1. **Создайте виртуальное окружение** (используем Python 3.12):
   ```bash
   py -3.12 -m venv venv
   ```

2. **Активируйте окружение**:
   ```bash
   .\venv\Scripts\Activate.ps1
   ```

3. **Установите зависимости**:
   ```bash
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. **Проверьте окружение**:
   Запустите проверочный скрипт (например, `check_env.py`), чтобы убедиться, что библиотеки `rasterio` и `pyproj` видят базу данных координат.

**Запуск Контейнеров**:
   Убедитесь, что Docker Desktop запущен, и выполните команду:
   ```bash
   docker-compose up -d --build
   ```
   Это поднимет три сервиса:
   *   **PostGIS (БД):** Доступна на порту `5432`.
   *   **MinIO (S3):** API на порту `9000`, Web-консоль на порту `9001`.
   *   **GIS-Service:** Приложение внутри контейнера.

**Инициализация базы данных (PostGIS)**
   
   !!! Для подключения pgAdmin к БД развернутой в Docker может понадобиться отключить службу postgre в services.msc. Локальный PostGRE работать, следовательно, не будет
   
   После первого запуска необходимо убедиться, что в базе включено расширение для работы с геоданными. 
   1. Подключитесь к базе через **pgAdmin**.
   2. Выполните SQL-запрос:
      ```sql
      CREATE EXTENSION IF NOT EXISTS postgis;
      ```
   3. Проверьте корректность установки командой: `SELECT PostGIS_Version();`.

**Проверка хранилища MinIO**
   1. Перейдите в браузере по адресу `http://localhost:9001`.
   2. Используйте логин/пароль из `.env`.
   3. Убедитесь, что бакет (по умолчанию `rasters`) создан автоматически. Если нет — создайте его вручную для корректной работы загрузчика.
